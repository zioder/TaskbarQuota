# Диагностика цикла разметки WinUI

Трассировка включается только при запуске TaskbarQuota с переменной окружения процесса `TASKBARQUOTA_LAYOUT_TRACE=1`. При обычном запуске она выключена. Флаг не изменяет настройки приложения и не исправляет причину `LayoutCycleException`.

Для подключения к уже запущенной диагностической сборке используйте 64-битный PowerShell:

```powershell
pwsh -NoProfile -File .\tools\diagnostics\Run-LiveLayoutTrace.ps1 -TargetId <PID>
```

По умолчанию сборщик проверяет, что выбранный процесс запущен из `artifacts/local/TaskbarQuota.exe`. Параметр `-ExpectedExecutable` позволяет явно указать другой исполняемый файл, например собственный тестовый emitter. Подключение отладчика может требовать прав администратора. Сборщик не управляет окнами, не меняет настройки и не завершает наблюдаемый процесс.

Захват ограничен 30 минутами и 4 МБ. Сохраняются разрешённые сведения о размерах, отступах, прокрутке и типах элементов. Записи с текстом интерфейса или неизвестным форматом отбрасываются целиком. Архив сохраняется в `artifacts/layout-traces`; временный каталог удаляется после успешного архивирования. Для досрочной остановки создайте пустой файл `stop` внутри текущего каталога `live-*`.

Проверки на собственных процессах без окон:

```powershell
pwsh -NoProfile -File .\tools\diagnostics\Test-LayoutTraceFilter.ps1
pwsh -NoProfile -File .\tools\diagnostics\Test-LayoutTraceCapture.ps1
pwsh -NoProfile -File .\tools\diagnostics\Test-LayoutTraceLimit.ps1
```

Эти проверки подтверждают работу сборщика, фильтрацию, ограничение объёма, отсоединение, остановку и обработку исключений самим тестовым процессом. Они не воспроизводят исходный сбой TaskbarQuota.
