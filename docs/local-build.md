# Локальная сборка для Windows

Постоянная папка программы – `artifacts\local`. Сборка предназначена для Windows x64 и требует .NET SDK 10.

Из корня репозитория:

```powershell
pwsh -File .\tools\Build-Local.ps1
```

Скрипт сначала собирает Release-версию в отдельную папку. После успешной сборки он останавливает только копию из `artifacts\local`, заменяет её новой и запускает виджет без главного окна. Предыдущая сборка сохраняется в `artifacts\local.previous` до следующей успешной пересборки. Одновременные запуски скрипта исключены блокировкой.

Если открыта другая установленная или переносимая копия TaskbarQuota, скрипт попросит закрыть её. При ошибке сборки работающая локальная копия остаётся нетронутой. Пользовательские настройки и учётные данные находятся отдельно, в `%LOCALAPPDATA%\TaskbarQuota`.

Для сборки без последующего запуска:

```powershell
pwsh -File .\tools\Build-Local.ps1 -NoStart
```

Автозапуск должен указывать на `artifacts\local\TaskbarQuota.exe` с аргументом `--startup-widget`. Скрипт не меняет автозапуск: при пересборках этот путь остаётся прежним.
